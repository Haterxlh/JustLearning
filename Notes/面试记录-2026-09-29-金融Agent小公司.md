# 面试记录｜2026-09-29｜金融 Agent 小公司

## 公司与岗位

- 规模：不到 10 人。
- 方向：金融 Agent。对方原话是"叫我了解下中美的金融 Agent"。
- 性质：了解型洽谈，没有进入技术多轮。

## 被问到的两个问题与我的回答

1. 知不知道大模型是怎么训练的？
   - 我的回答：在 transformer 架构下训练的。自己判断这个回答不准确——GPT 这类只用了 transformer 的解码器。
   - 结果：对方没有继续追问。
2. 中美的大模型有什么区别？
   - 我的回答："美国的大模型会更加全面"之类的笼统话。
   - 原因：平时不翻墙、国外模型价格高，没有实际用过，只根据 B 站视频的印象回答。

## 暴露的缺口与去向

| 缺口 | 去向 |

| "大模型怎么训练"讲不出流程（三段式的数据、目标、典型超参） | W3「DL 基础 + 训练全流程 + 资源核算」当周验收加一条：**3 分钟讲清 GPT 式训练全流程（预训练 → SFT → 偏好对齐）**，不看资料 |
