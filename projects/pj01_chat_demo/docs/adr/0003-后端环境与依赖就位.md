# 后端环境与依赖就位（第 1 步小步 1）

2026-10-20 按第 1 步先做后端环境：虚拟环境、依赖清单、安装与导入验证。

## 决定

- 用 `uv venv --python 3.12` 建环境，解释器版本与 Anaconda 的 3.12 一致。
- 依赖写进 `backend/requirements.txt` 九项：`fastapi`、`uvicorn[standard]`、`sqlalchemy[asyncio]`、`asyncpg`、`pydantic-settings`、`PyJWT`、`bcrypt`、`pgvector`、`email-validator`。
- 安装用 `uv pip install -r requirements.txt`；环境内不装 pip，后续装包统一用 `uv pip`。

## 考虑过的选项

- 用标准库 `venv`：可用，装依赖比 uv 慢；本机已装 uv，沿用同一套工具。
- 用 conda 的 `pytorch-01` 环境：与学习项目混在一起，依赖版本与端口互相干扰。

## 后果

- 导入检查通过：`fastapi`、`sqlalchemy`、`asyncpg`、`jwt`、`bcrypt`、`pgvector`、`pydantic_settings` 都能 import。
- 环境目录为 `backend/.venv`；项目级 `.gitignore` 在小步 4 建立，届时把 `.venv/` 列入忽略。
- 下一步做小步 2：前端 Vite 骨架。
