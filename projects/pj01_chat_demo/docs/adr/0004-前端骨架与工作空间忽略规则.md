# 前端骨架与工作空间忽略规则（第 1 步小步 2）

2026-10-20 生成前端骨架并补齐工作空间根目录的忽略规则。

## 决定

- 用 `npm create vite@latest frontend -- --template react-ts` 生成骨架，交互里的 linter 选 ESLint。
- 模板自带的演示页与演示资源保留到第 2 步再替换，第 1 步只确认开发服务器与热更新可用。
- 根目录 `.gitignore` 新增两段：
  - Node 与前端：`node_modules/`、`dist/`、`dist-ssr/`、`.vite/`、`npm-debug.log*`、`*.local`。
  - 环境变量与密钥：`.env`、`.env.*`，保留 `!.env.example`。
- 保留模板自带的 `frontend/.gitignore`，不删除。
- 模型权重的 `models/` 改成 `/models/`：不带斜杠的目录规则会匹配任意层级同名目录，把 `backend/app/models/` 这类代码目录一起挡掉；带前导斜杠只匹配仓库根目录。

## 考虑过的选项

- 删除 `frontend/.gitignore`，规则只写在根目录：模板那份还带 `!.vscode/extensions.json` 等条目，删除会丢掉这些例外；两份并存时 git 按层级分别匹配，重复的规则不冲突。
- 用 `git update-index --skip-worktree` 之类的办法绕开：根目录规则一次写清就够，不需要额外机制。

## 后果

- 版本：React 19.3.1、Vite 8.3.4、TypeScript 6.0.3、ESLint 10.13.0。

- `npm run dev` 启动成功，浏览器默认页计数器正常，按 `Ctrl+C` 已停止。
- `git check-ignore` 验证：`node_modules/react/index.js`、`dist/index.html`、`backend/.env`、`frontend/.env.local` 均被忽略。
