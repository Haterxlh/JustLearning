# 分步教学与提问记录

2026-10-20 本人要求这个 demo 由自己动手，agent 讲步骤、本人执行命令；一次只给一个小步，不一次性输出整条流程；本人自行判断结果，只在出错时贴报错原文。同时要求把过程中提出的问题与简要回答留档。

## 决定

- 三步推进：第 1 步搭框架（agent 只讲命令与预期结果，不改文件）；第 2 步登录注册（agent 写代码）；第 3 步对话与 SSE（agent 讲步骤，本人写代码）。
- 第 1 步拆成五个小步，逐个交付，每个在十几分钟内可验证。
- 讲解用通俗简洁的中文；出现"这个""它"这类代词时指明具体对象。
- 提问记录写入 `docs/questions/YYYY-MM-DD.md`，一天一个文件；静默写入，不在对话里声明；代词换成具体对象；只写问题与简要回答。
- 进度与决定写入 `docs/adr/`，每完成一个小步或一个阶段追加一条。

## 考虑过的选项

- 一次给完整教程：与本人动手的方式冲突，出错后难以定位到哪一步。
- 只记录提问原文：代词多，隔天回看找不到指代对象。
- 把进度写进 README：README 的职责变成流水账，接口契约与计划被埋住。

## 后果

- 回看过程先读 `docs/adr/`，再按日期读 `docs/questions/`。
- README 只保留目标、接口契约、分步计划、协作约定。
