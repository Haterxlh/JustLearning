### 字符串hash问题
有问题的代码：
```python
def hashs(self, s: str) -> str:
    hs = [0 for _ in range(ord("z") - ord("a") + 1)]
    for ch in s:
        idx = ord(ch) - ord("a")
        hs[idx] += 1
    return "".join(map(str, hs))
```
> 当计数超过 9 时会产生歧义。例如：
> 
> [1, 11] → "111"
> 
> [11, 1] → "111"


```python
def hashs(self, s: str) -> str:
    hs = [0 for _ in range(26)] # 直接26，题目保证了全是小写字母
    for ch in s:
        idx = ord(ch) - ord("a")
        hs[idx] += 1
    return ",".join(map(str, hs)) # 不加分隔符会导致歧义
```

更优的做法直接用元组做hash
```python
def hashs(self, s: str) -> tuple:
    cnt = [0 for _ in range(26)] # 直接26，题目保证了全是小写字母
    for ch in s:
        idx = ord(ch) - ord("a")
        cnt[idx] += 1
    return tuple(cnt) # 不加分隔符会导致歧义
```
