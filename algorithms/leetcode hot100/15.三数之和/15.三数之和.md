问题：
1. 结果中的数对应的编号不一定 i < j < k
2. 即使不做

    也没有去重
3. 空间 n^2 
4. 二分只找了一个解

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        n = len(nums)
        res = []
        for i in range(n - 2):
            # 对 nums[i] 去重
            if i and nums[i - 1] == nums[i]:
                continue
            j = i + 1
            k = n - 1
            while j < k:
                s = nums[i] + nums[j] + nums[k]
                if s > 0:
                    k -= 1
                elif s < 0:
                    j += 1
                else:
                    res.append([nums[i], nums[j], nums[k]])
                    # 去重
                    while j < k and nums[j] == nums[j + 1]:
                        j += 1
                    while j < k and nums[k] == nums[k - 1]:
                        k -= 1
                    j += 1
                    k -= 1
        return res
```

为什么不写：
```python
# 对 nums[i] 去重
if i + 1 < n - 2 and nums[i + 1] == nums[i]:
    continue
```
> 解题时,i 是三元组里最小的那个数。当解里出现「两个相同的数」时(如 [-1, -1, 2]),这两个 -1 都来自数组里相邻的位置。
> 
> 正确做法:
> 
> 让 i 落在重复段的第一个 -1(位置 0),然后 l 从位置 1(第二个 -1)开始,才能取到 [-1, -1, 2]。
> 
> 你的做法:
> 
> 跳过了位置 0,只保留位置 1。此时 l 只能从位置 2 开始,永远取不到第二个 -1,这个解就丢了。
